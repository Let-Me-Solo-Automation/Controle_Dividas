# Assinatura do APK

A chave original desta instalação foi preservada fora do repositório. O APK 2.1.1 usa a mesma chave que o APK 2.1.0.

O ZIP contendo o keystore e sua senha **não será colocado aqui enquanto a API do GitHub informar que o repositório é público**. O proprietário pode alterar a visibilidade em Settings → Danger Zone → Change repository visibility → Make private. Depois da confirmação da visibilidade privada, o arquivo pode ser transferido para esta pasta.

Não gere outra chave para tentar atualizar uma instalação existente: a identidade do assinante precisa permanecer a mesma. A chave não é necessária para instalar o APK fornecido; é necessária para gerar futuras atualizações compatíveis.
